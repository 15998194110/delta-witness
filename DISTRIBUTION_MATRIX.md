# DELTA Witness v0.6 — Omnidistribution Matrix

Priority is fully-automated or marketplace-native acquisition. Human-maintained social posting is intentionally secondary.

## Tier S — deploy immediately

1. x402 Bazaar / Agentic Market — protocol-native discovery after successful verify+settle.
2. x402 aggregators — x402-list imports from Bazaar/x402scan automatically.
3. Search engines — sitemap + IndexNow scheduled push for static commercial pages.
4. Agent-readable surfaces — OpenAPI, llms.txt, SKILL.md, x402 manifest.

## Tier A — one-time account/bootstrap required

5. Official MCP Registry — publish an adapter package to npm then register metadata.
6. Smithery + Glama — publish/claim the same MCP adapter for additional agent distribution.
7. Postman API Network — import /postman.json and publish a public workspace.
8. Base.dev — the deployed standard web app provides Paste URL → quote → injected-wallet x402 payment → proof; Base.dev registration and builder attribution require one-time account/developer approval.
9. Apify Store — publish DELTA capture as a pay-per-event Actor; after KYC, eligible Actors can be discovered and paid by agents via x402/Skyfire.
10. RapidAPI — list a card-payment/API-key wrapper for conventional developers; use marketplace billing rather than x402.

## Tier B — package/workflow discovery

11. npm SDK / CLI — keywords make packages searchable; can be a prerequisite for MCP/n8n.
12. PyPI SDK — Python agent/developer discovery.
13. n8n community node — npm package + Creator Portal verification.
14. Chrome Web Store / Firefox Add-ons — one-click 'Witness this page' human acquisition.
15. Docker Hub — self-hosting and developer trust/discovery, lower direct conversion priority.

## Do not prioritize yet

- Paid social ads before LTV is measured.
- Mass unsolicited outreach.
- Token launch/NFT incentives.
- Thin programmatic SEO pages.
- Google Indexing API misuse (general DELTA pages are not JobPosting/BroadcastEvent).
